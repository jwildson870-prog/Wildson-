# 🥙 Tapioca da Dona Maria

## Descrição

O **Tapioca da Dona Maria** é um sistema desenvolvido em Python que simula o atendimento de uma tapiocaria. O programa permite que o cliente escolha os sabores desejados, calcule automaticamente o valor da compra, selecione a forma de pagamento e receba uma nota fiscal ao final do pedido.

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da linguagem Python, como funções, estruturas de repetição, condicionais, variáveis globais e menus interativos.

---

## Funcionalidades

- Cardápio com diferentes sabores de tapioca.
- Escolha da quantidade de cada pedido.
- Limite mínimo e máximo de pedidos por sabor.
- Soma automática do valor total da compra.
- Consulta do valor total antes de finalizar o pedido.
- Três formas de pagamento:
  - Dinheiro (10% de desconto);
  - Pix (5% de desconto);
  - Cartão (sem desconto).
- Cálculo automático do desconto.
- Cálculo do valor final da compra.
- Cálculo do troco para pagamentos em dinheiro.
- Emissão de uma nota fiscal ao final do pedido.
- Menu interativo utilizando `match/case`.
- Validação das opções do menu.

## Como executar

1. Execute o arquivo Python.
2. Escolha os sabores desejados.
3. Informe a quantidade de cada tapioca.
4. Consulte o valor total, se desejar.
5. Escolha a forma de pagamento.
6. Finalize o pedido e visualize a nota fiscal.
